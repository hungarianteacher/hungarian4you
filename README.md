# Hungarian4You

A hungarian4you.com weboldal forráskódja, GitHub Pages-en üzemeltetve.

## Struktúra

- `students/` — a tanulói anyagok (leckék, szókincs, nyelvtan, gyakorlatok, audio)
- `index.html` — a gyökér oldalról átirányít a `students/` mappára

## Fejlesztés

Minden lecke saját HTML fájl a `students/` mappában, közös `style.css`-t és `shared/site-widgets.js`-t használva.
